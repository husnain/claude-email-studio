# Customer Reviews — Batch 6 (101–120)

---

**Review 101** ★★★★★
**Bilal Nawaz — Owner, Chargha & Chai Express**

We handle queues at lunch and table service at dinner. The switch between the two modes — counter and table service — is on the same screen, same account. I didn't have to buy a separate system or configure anything elaborate. This flexibility was the deciding factor when I signed up. It's delivered exactly what was described.

**Review 102** ★★★☆☆
**Sadaf Hussain — Manager, Karahi & Roti House**

The system is reliable. I want to flag a usability issue: the button for applying a discount and the button for applying a complimentary item are very close together on the payment screen. We've accidentally comped items when we meant to discount them twice now. The layout should put more distance between those two actions, or require a different gesture for a comp versus a discount.

**Review 103** ★★★★☆
**Zaheer Ahmed — Owner, Lahori Kebab Station**

We added a dessert counter eight months into using MezbanPOS. Setting it up as a separate station with its own printer and its own queue was straightforward. The kitchen display for the main kitchen still shows dessert orders, which is what I wanted — the head chef sees the full picture. I'd rate it higher if the dessert station had a quick-access screen by default rather than making me build it from scratch.

**Review 104** ★★★★★
**Ambreen Chaudhry — Owner, Desi Pantry & Grill**

We're a family business and my parents are involved in the floor. Neither of them is comfortable with technology. If that's not an accessible interface, I don't know what is. The font sizes help, and so does the confirmation screen before every order fires.

**Review 106** ★★★★★
**Huma Khan — Owner, The Lahori Sofra Co.**

The evening summary screen at close of day has become my favourite part of running a restaurant. Total covers, average spend per cover, top five items by revenue, VAT summary, cash vs card split. **Review 107** ★★★★☆
**Sajid Chaudhry — Owner, Pindi Murgh Co., Leicester**

We added a second location three months ago and the multi-site reporting is genuinely useful — I can compare revenue, covers, and average spend between both locations on the same screen. The limitation I've hit: I can't create a menu item at both locations simultaneously. I have to add it to Location 1, then switch to Location 2 and add it again. For a 50-item menu that's manageable; for a 150-item menu it would be painful.

**Review 110** ★★★★☆

**Review 112** ★★★★★

**Review 113** ★★★★☆
**Mohsin Bhatti — Owner, Lahori Chargha & Chips**

We use the age verification prompt feature for our alcohol menu. When a server taps on an alcoholic item, the screen asks them to confirm the customer has been ID'd. It's a soft prompt — the server can confirm with one tap — but it means there's always a logged record of the confirmation. We haven't had a compliance issue since we switched. The only thing I'd add: a way to flag a table as age-verified at the start of a session so the prompt doesn't repeat for every round.

We added catering as a revenue line six months after opening.
